# Отчет по лабораторной работе №5
## Тема: Параллельное умножение матриц с использованием MPI

### 1. Цель работы
Изучить основы параллельного программирования с использованием технологии MPI, реализовать параллельный алгоритм умножения квадратных матриц, провести вычислительные эксперименты и оценить полученное ускорение.

### 2. Описание алгоритма и реализации
Программа реализует параллельное умножение матриц по модели распределенной памяти средствами MPI:
1. Процесс с рангом 0 считывает исходные квадратные матрицы $A$ и $B$ из файлов в папке `data/`.
2. Размер матрицы $N$ и вся матрица $B$ транслируются всем процессам через функцию `MPI_Bcast`.
3. Строки матрицы $A$ равномерно распределяются между процессами с помощью функции `MPI_Scatter`. Каждый процесс получает порцию из `rows = n / size` строк.
4. Каждый процесс параллельно вычисляет свою часть результирующей матрицы $C$.
5. Сборка финальной матрицы $C$ на процессе 0 осуществляется через функцию `MPI_Gather`.
6. Замер времени производится на процессе 0 с помощью `std::chrono::high_resolution_clock` вокруг вычислительного блока. Результаты логируются в файл `results_mpi.csv`.

### 4. Результаты экспериментов

Эксперименты проводились для квадратных матриц размерностью от 200 до 2000 на конфигурациях из 1, 2 и 4 процессов.

#### Таблица 1. Время выполнения (в миллисекундах)
| Размер матрицы | 1 процесс ($T_1$) | 2 процесса ($T_2$) | 4 процесса ($T_4$) |
| :--- | :--- | :--- | :--- |
| **200x200** | 83.6 | 42.5 | 21.7 |
| **400x400** | 657.4 | 329.3 | 166.3 |
| **800x800** | 4868.8 | 2554.3 | 1330.6 |
| **1200x1200** | 15905.0 | 8084.1 | 4275.9 |
| **1600x1600** | 37918.0 | 19046.2 | 9849.6 |
| **2000x2000** | 73732.0 | 36985.3 | 19013.3 |

### 5. Анализ результатов и вывод
* **Эффективность масштабирования:** При увеличении числа процессов время выполнения задачи уменьшается практически линейно. На 4 процессах для максимального размера матрицы $2000 \times 2000$ время сократилось с 73.73 до 19.01 секунд.
* **Показатели скорости:** Максимальное ускорение составило **3.95×** на 4 процессах (для матрицы $400 \times 400$), что крайне близко к идеальному теоретическому ускорению ($4.0$).
* **Равномерность нагрузки:** Разделение матрицы $A$ по строкам через блочное распределение обеспечило сбалансированную загрузку всех занятых ядер без простоев.

**Вывод:** Реализованный MPI-алгоритм продемонстрировал высокую эффективность параллелизации и хорошую масштабируемость на многопроцессорной системе. Цель работы достигнута.
